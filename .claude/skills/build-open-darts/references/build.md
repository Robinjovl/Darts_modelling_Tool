# Skill: Build open-DARTS

## Overview

open-DARTS is a hybrid Python/C++ project. Building involves two phases:
1. **C++ extensions** — compiled via CMake (engines, discretizer, solvers).
2. **Python package** — installed via pip/setuptools from `pyproject.toml`.

---

## Prerequisites

- Python >= 3.10 (tested on 3.10–3.13)
- CMake >= 3.26
- C++20-capable compiler: GCC, Clang, or MSVC
- Git (for submodule checkout)
- pip, setuptools >= 70, wheel

Optional:
- Conda (for Reaktoro chemistry library)
- CUDA toolkit (for GPU builds)
- `bos_solvers` library (for MT and GPU configurations)

---

## Conda Environment Policy

Use a prompt-defined conda environment when the task or user already names one.
Otherwise create and activate one session-level environment at the first build,
install, test, debug, docs, or lint step, then reuse it across all skills for
the rest of the session.

Default session environment:

```bash
conda create -y -n open-darts-session python=3.11
conda activate open-darts-session
```

Guidance:

- Prefer Python 3.11 unless the task explicitly targets a different supported
  version.
- Keep build, install, test, lint, docs, and follow-up smoke tests in the same
  session environment.
- When using `-p` for Reaktoro, stay on Python 3.10-3.12.

## Quick Start: Full Build + Install (Linux)

From the repo root:

```bash
# Full build: submodules, thirdparty libs, C++ extensions, Python wheel, install
./helper_scripts/build_darts_cmake.sh -c -w -p -m -j 8
```

Key flags for `build_darts_cmake.sh`:

| Flag | Description |
|---|---|
| `-c` | Clean build (removes `build/` directory first) |
| `-w` | Generate Python wheel in `dist/` |
| `-t` | Enable C++ testing (ctest) |
| `-m` | Multi-threaded build (requires bos_solvers via `-a` or `-b`) |
| `-G` | GPU build (requires CUDA + bos_solvers) |
| `-r` | Skip rebuilding thirdparty libraries |
| `-a` | Fetch private bos_solvers from artifacts (CI use) |
| `-b PATH` | Path to pre-compiled bos_solvers |
| `-d MODE` | Build type: `Release` (default) or `Debug` |
| `-j N` | Parallel compilation threads (default: 8) |
| `-g VER` | Specify compiler, e.g. `-g g++-13` |
| `-p` | Build + install IPhreeqc and Reaktoro (conda required) |
| `-v` | Valgrind-compatible build (forces Debug) |

## Quick Install (Editable Mode, No Full Rebuild)

If C++ extensions are already compiled (the `build/` directory exists):

```bash
./helper_scripts/install_darts.sh -e -j8
```

Flags:
- `-e` — editable pip install (changes to Python code take effect immediately)
- `--with-deps` — also install Python dependencies
- `-jN` — parallel make threads

This script runs `make -j8` in the existing `build/` directory, then installs
the Python package.

## Troubleshooting

| Problem | Solution |
|---|---|
| CMake can't find Python | Ensure correct Python is first in `PATH`; use conda env |
| Missing pybind11 | Run `git submodule update --init --recursive` |
| SuperLU build fails on macOS | Use the macOS-specific `conf.mk` and `make.inc` |
| "OPENDARTS_CONFIG MT requires bos_solvers" | Use `-a` flag or provide `-b /path/to/solvers` |
| Old build artifacts | Use `-c` flag for clean build |
| Reaktoro not found | Activate conda env, use `-p` flag, Python must be < 3.13 |
